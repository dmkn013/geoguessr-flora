# タグ付けエージェント用プロンプト雛形

10,000枚を Sonnet サブエージェントで処理する。以下をそのまま渡す。
`{N}` は処理ページ数の上限（コンテキスト切れを避けるため4〜6が目安）。

---

GeoGuessr学習教材の画像タグ付けです。日本語で回答してください。

**車載写真に、写っている植物のタグを付けてください。最大{N}ページ処理したら報告して終了。ページ数厳守。**

対象は2種類の写真が混ざっています（どちらも同じ扱いでタグを付けてください）:
- 世界からランダムに引いたもの
- 48種の分布域から引いたもの（過去の収集分。捨てずに再利用している）

手順（「完了:」が出るまで繰り返す）:

1. Bash実行:
`PYTHONIOENCODING=utf-8 python src/tag_sheet.py next`
→「完了:」なら終了。画像パスが出たら次へ。

2. Readツールでその画像を開く。車載カメラの道路風景が最大9枚、左上に黒地白文字の通し番号（0始まり）と座標。

3. 各画像について、**識別できる植物**をタグにする。

**粒度: 属レベルを基本とし、種まで分かれば種も付ける。**
- 例) 幹がオレンジの北欧の松 → `マツ属 ヨーロッパアカマツ`
- 例) 遠景で属しか分からない → `マツ属`
- 例) 垂れ下がる細い葉の豪州の木 → `ユーカリ属`
- 例) 巨大な裂けた葉 → `バショウ属 バナナ`

**付けてよいもの**: 分類群の名前（マツ属、ヤシ科、ユーカリ属、サトウキビ、バナナ…）
**付けてはいけないもの**: 植生タイプ（針葉樹林、広葉樹林、草地、農地、砂漠…）

**方針:**
- 1枚に複数タグ可。写っているものは全部書く。
- **迷ったら書かない**。「たぶんユーカリ」は書かない。属レベルなら言えるならそれを書く。
- 座標は参考にしてよいが、座標だけを根拠にタグを付けない（画面に写っていることが条件）。
- 識別できる植物が1つも無い場合（道路・空だけ、市街地、霞んで不明、暗すぎる）は none にする。

4. Bashで記録:
- タグを付ける（画像1枚ごとに1コマンド、タグはスペース区切り）:
`cd /c/Users/shun/OneDrive/work/geoguessr-flora && PYTHONIOENCODING=utf-8 python src/tag_sheet.py set 3 マツ属 ヨーロッパアカマツ`
- 植物が識別できないものはまとめて:
`cd /c/Users/shun/OneDrive/work/geoguessr-flora && PYTHONIOENCODING=utf-8 python src/tag_sheet.py none 0 1 2 4`

**9枚すべてについて set か none のどちらかを必ず実行すること。** 記録しないと次のシートに残り続ける。

5. 手順1に戻る。

最後に「Nページ処理 / タグ付けM枚 / うち植物なしK枚」と、付けた主なタグを報告してください。
