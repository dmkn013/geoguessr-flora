# 実写画像の目視確認ログ（2026-08-29）

48種すべてを目視した。判定基準は
**「その種の `tells[0]`（＝GeoGuessrで最初に見る特徴）が写っているか」**。

## 分かったこと: `prop=pageimages` は教材用途には向かない

`prop=pageimages` が返すのは記事の**先頭画像**で、植物記事の先頭画像は

- 19世紀の植物図版（Köhler の医薬植物図譜など）… ゴム・ココヤシ・スギ・サラノキ・アブラヤシ
- 果実／葉のクローズアップ … バナナ（店頭の果実）・チーク・ナツメヤシ・オリーブ・サトウカエデ
- 製品の写真 … コルクガシ（コルク粒のテクスチャ）

になりがちだった。図鑑としては正しいが、GeoGuessr で見るのは
**道端から見た木の形・樹皮・並び方**なので、そのままでは使えない。
48種中12種（4分の1）がこれで落ちた。

## 取り直しでやったこと

1. **別記事を引く**（栽培・景観寄りの記事へ）→ リダイレクトで元の図版に戻る種が多く、部分的な成功
2. **Commons のカテゴリを引く** → カテゴリ名を推測したものはほとんど存在せず失敗
3. **Commons を検索する** → 関連度が低い（オリーブ→カリフォルニアのブドウ園、アブラヤシ→衛星画像）
4. **カテゴリを実際に列挙して、存在するファイル名から選ぶ** → これが効いた

**教訓: ファイル名を推測で書くと全滅する。**
1巡目の直指定は8種すべて「存在しない名前」で失敗した。
名前を作るのではなく、列挙して**あるものから選ぶ**。

## コルクガシについて

前回からの申し送りだった「剥皮された赤い幹が見えない」は**未解決**。
現在の画像は montado（疎林の景観）で、種の同定には使えるが
**コルクガシ最大の手がかりである赤褐色の剥皮跡は写っていない**。
`tells` の1つ目と画像が一致していない唯一の種なので、次に直すならここ。
