## やったこと

2. `review_photos.py` … 48種のコンタクトシートを作って**全種を目視**

## 一番の学び: `prop=pageimages` は教材用途には向かない

返ってくるのは記事の**先頭画像**で、植物記事の先頭画像は

- 19世紀の植物図版（Köhler の医薬植物図譜）… ゴム・ココヤシ・スギ・サラノキ・アブラヤシ
- 果実／葉のクローズアップ … バナナ（**店頭に並んだ果実**だった）・チーク・ナツメヤシ・オリーブ
- 製品の写真 … コルクガシ（**コルク粒のテクスチャ**）

になりがち。**48種中12種（4分の1）がこれで落ちた**。
前回コルクガシ1種で気づいた問題は、実際には全体の1/4に及ぶ構造的な問題だった。

## 詰まったこと: ファイル名を推測すると全滅する

差し替えで4通り試した。

| やり方 | 結果 |
|---|---|
| 別記事を引く（栽培・景観寄りへ） | リダイレクトで元の図版に戻る種が多い。部分的な成功 |
| Commons のカテゴリ名を推測して引く | ほとんど存在しないカテゴリ。ほぼ全滅 |
| Commons を検索する | 関連度が低い（オリーブ→カリフォルニアのブドウ園、アブラヤシ→**衛星画像**） |
| **カテゴリを列挙して実在するものから選ぶ** | **これが効いた** |

ファイル名を直指定した1巡目は、**8種すべて「存在しない名前」**で失敗した。
自分で尤もらしい名前を作ってしまっていた。
`list_commons.py` を用意したのはこのため。**作らずに、あるものから選ぶ**。
