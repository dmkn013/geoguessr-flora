# 詳細分類と上位分類の集計

`data/taxon_catalog.json`の`parent`は親の学名を指す。`parent_source`に分類関係を照合した資料を残す。種→属→科、将来の変種→種→属→科など、登録された関係を再帰的にたどる。未知の関係を名前から推測しない。親の参照先がない場合、循環がある場合、正式和名が重複する場合はビルドを拒否する。

`python src/plant_review.py build`は従来の`plant_review_tags.json`に加えて、`data/plant_review_taxa.json`と`dist/plant_reviews/taxonomy.json`を生成する。

- `direct_image_counts`: 画像から直接確定した分類名ごとの画像数。複数個体がいても同じ画像・分類は1件。
- `inclusive_image_counts`: 下位分類も含む画像数。複数の種や明示的な科タグが同じ写真にあっても、その科の画像数は1件。
- `reviewed_images`: completeで、種以下の確定対象に再確認待ちがない画像数。確定タグが0個の画像を含む。
- `tagged_images`: 上記のうち確定した分類タグが1個以上ある画像数。種まで判明した画像数ではない。

一次確認のみの画像、暫定候補、未同定対象を確定分類の集計に入れない。種以下の確定対象にQA待ちがある画像は、従来どおり地図向けの更新全体を保留する。元の矩形・根拠・候補・対象別の分類と既存履歴は集計から書き戻さない。

地図は詳細タグをそのまま写真に表示し、色の選択と凡例では全階層の祖先を考慮する。たとえば科・属・種が併記された点では種を優先する。地図の`taxonomy`メタデータにも直接件数と下位を含む件数を残す。こちらは旧タグも含む地図表示対象の集計なので、詳細レビューだけの集計と母集団が違う。旧タグの分類精度が新方式で検証されたことにはならない。

現時点の100枚では確定分類を持つ画像は38枚。ヤシ科の直接画像数は26、アブラヤシ属まで分かった画像を含めると27。キョウチクトウとインドソケイ属はそれぞれ1画像で、両者を含むキョウチクトウ科は2画像。同定済み対象数63と画像数は異なる。

検証は`python -m unittest discover -s tests -v`。親の欠落・循環、複数階層、兄弟分類/重複対象/明示的な親タグの重複、候補や一次確認・QA待ちの除外を含む12件を通過済み。
