## 分かったこと

**48種の約半数（23種）が遭遇率0%。** 分布域は正しいのに道端からは見えない。

理由は立地にある:
- マングローブ → 水際
- 竹林 → 谷筋
- パラゴムノキ → 私有地の奥
- カラマツ → 高標高
- サルオガセモドキ → 湿地の樹上
- グラスツリー → 山火事跡の斜面

いずれも幹線道路の視界から外れる。Mapillary は主要道路の投稿が中心なので写らない。

**「有名で絵になるメタほど遭遇率が低い」** という傾向が数字で出た。
トスカーナの糸杉、地中海のオリーブ園、京都の竹林はいずれも0%。
一方ユーカリ（40%）は地味だが道端に普通にある。

## 判定の進め方

画像を読むと自分のコンテキストに入るため、判定モデルはセッションのモデルになる。
大量の画像分類にOpusを使わないよう、**Sonnetのサブエージェント**に委譲した。

- 検証: サトウカエデ9枚でSonnetと自分の判定が完全一致（全て却下）してから移行
- `judge_one.py` で next/ok/ng を繰り返し、1エージェントが1〜3種を担当
- **1エージェントあたり4〜6ページ（36〜54枚）に制限**。
  40枚を1エージェントに任せるとコンテキスト不足で中断する事故が2回起きた
- 状態は1枚ごとにディスク保存。中断しても取りこぼしなし

判定方針は全エージェント共通で「**迷ったら却下**」。
種を特定できない遠景、暗すぎる画像、紛らわしい近縁種は却下。
ヤシ類は取り違えやすいので、種ごとに「何と混同するな」を明示した。
